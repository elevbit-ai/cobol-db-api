Endpoints da API

API RESTful para integracao com sistemas externos.

POST /api/save Salvar novo registro no banco de dados
POST /api/upload Upload de arquivo e vinculo a registro
POST /api/bind Vincular upload existente a registro
GET /api/list Listar todos os registros cadastrados
GET /api/record/{id} Obter registro especifico por ID
GET /api/uploads/{record_id} Listar uploads vinculados a um registro

Exemplo de Requisicao (cURL)

curl -X POST http://localhost:8080/api/save \
  -H "Content-Type: application/json" \
  -d '{
    "nome": "Joaquim Pedro",
    "email": "j360074@hotmail.com",
    "telefone": "(85) 99999-0000",
    "endereco": "Rua Example, 123",
    "cidade": "Fortaleza",
    "uf": "CE"
  }'
